## Shipped (prototype, October 2026)

- [x] 1. **Real-world map pipeline** - OpenStreetMap and SRTM converted to `world.json` and `heightmap.json` by the Python tools
- [x] 2. **Generated suburb** - terrain, roads with markings and street lights, houses from outlines, fields, fences, streams, signs, parked cars
- [x] 3. **Player on foot** - walk, sprint, jump, aim, shoot, reload, two weapons, slow-motion aiming, stamina
- [x] 4. **Driving** - cars and taxis on vehicle physics, enter and exit, chase camera, lights, horn, call the car back
- [x] 5. **NPCs and factions** - residents, police and gang with wander, patrol, alert, combat and death
- [x] 6. **Dialogue** - JSON conversation trees with conditions and actions
- [x] 7. **Missions** - goto, kill_group, talk and return steps, spawns, rewards, HUD marker
- [x] 8. **Wanted system** - witnesses, heat levels, decay, admission-of-guilt fine
- [x] 9. **Day, night and weather** - sun, moon, fog, lamps, five weather states
- [x] 10. **UI** - HUD, minimap, world map with waypoints and location names, pause menu, settings, graphics tiers
- [x] 11. **Save and load** - single slot in `user://save.json`
- [x] 12. **Per-building overrides** - roof, wall, facade photo or 3D model by OpenStreetMap id
- [x] 13. **Smoke test** - `--smoke` plays through the game and exits non-zero on failure

## First: the real suburb

- [x] 20. **House numbers, addresses and real places** - every building gets its municipal address (eThekwini open data), plates by the door, HUD address, map numbers and search; schools, places of worship, library, hall, pool, clinics, hospital, shopping centres, stadia and parks exist with real names

## MVP: SOLID without breaking the game

- [ ] 14. **Unit test runner** - `tests/Veld.Tests` (xUnit) for pure logic, wired into the build and documented in `AGENTS.md`
- [ ] 15. **Game services seam** - `IClock`, `IEconomy` and `INotifier` extracted from `Game` and injected into `MissionManager`, `DialogueSystem` and `WantedSystem`, with first tests at that seam
- [ ] 16. **Mission step registry** - `IMissionStep` implementations looked up by type name replace the switches in `MissionManager`; existing JSON unchanged
- [ ] 17. **Dialogue action and condition registries** - the same treatment for `DialogueSystem.Holds` and `Apply`
- [ ] 18. **Retire the Game singleton** - remaining `Game.Instance` call sites replaced with services composed in `Main`, UI first, then World, then Characters
- [ ] 19. **Simulation and presentation split** - a `Veld.Sim` library holding world, mission, NPC and economy state at a fixed tick; Godot nodes render and forward input

## Post-MVP: enhancements

- [ ] 20. **House numbers and addresses** - numbers generated per road in the converter, plates by the door, HUD address, map search
- [ ] 21. **Roofs for any outline** - hip roofs on L and T shaped houses, not only rectangles
- [ ] 22. **Landmark models** - stadium, shopping centre, police station, schools and filling stations as real models via overrides
- [ ] 23. **Animals** - dogs, monkeys and birds that wander and flee
- [ ] 24. **Android build** - Mobile renderer preset, touch controls, performance tiers, runs on a real phone
- [ ] 25. **More missions** - six to eight on the launch map, with new step types as needed
- [ ] 26. **Multiplayer co-op** - server-authoritative, two to four players in one suburb, after item 19
