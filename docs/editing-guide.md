# Editing guide

Everything below can be done with a text editor and a restart. Run the smoke test afterwards
(`--smoke`, see the README) or just play.

Coordinates: `[x, z]` in metres from the map centre. The map is 1600 m wide, so valid values are about
-780 to 780. Height is always taken from the terrain. In Godot, -z is "north" on the HUD compass.

## Real-world maps (Chatsworth and others)

A real map folder holds `world.json` (roads, areas, buildings, lines, points of interest, settings)
and `heightmap.json` (elevation grid), both generated by `tools/osm_to_map.py`, plus the hand-written
`npcs.json`, `dialogue.json`, `missions.json`, `weapons.json` and (optional) `towns.json`.

To regenerate Chatsworth after editing the converter:

```
python tools/osm_to_map.py tools/source/montford_osm.json tools/source/montford_elevation.json data/maps/chatsworth-unit7
```

To map a different suburb:

1. Open `tools/osm_fetch.py`, change `box` (south,west,north,east) to a box around the place and the
   name pattern on the `q1` line (Chatsworth units number their roads, e.g. `^7[0-9][0-9] Road$`; for
   another suburb use the suburb's known streets, or replace step 1 with a fixed extent). Run it; it
   prints the extent and writes `<place>_osm.json`.
2. Download elevation tiles for that extent (`tools/terrarium.py` reads Terrarium PNG tiles from
   `https://s3.amazonaws.com/elevation-tiles-prod/terrarium/14/{x}/{y}.png`; the x/y for a latitude
   and longitude are the standard web-mercator tile numbers at zoom 14).
3. Run `osm_to_map.py` into `data/maps/<your-id>`, write the character files, set `data/config.json`.

What the converter understands: `highway=*` ways become roads (width by kind), `building=*` become
footprints (hip roof if the outline is a rectangle under 320 m², flat otherwise; `building:levels`
sets storeys), `leisure=pitch/park/stadium`, `landuse=grass/wood/parking...` become areas (pitches
and car parks are levelled), `waterway`, `barrier=fence/wall`, `power=line` become lines, and shops,
schools, police etc. become signs. Add a new kind by extending the `switch` statements in
`WorldBuilder.Build`, `RoadBuilder`, `FootprintBuilder.AddBuilding` or `Dressing`.

Positions in the character files are absolute metres from the map centre (x east, z south). Run
`python -c "..."` over `world.json`, or just walk there in the game and read the position off the
F12 screenshot's name, to find coordinates.

## Change the landscape

`data/world.json`:

- `seed`: any integer, a different landscape.
- `sizeMeters`, `cellSize`: map size and mesh resolution. 1600 / 4 is 160k vertices; 2400 / 4 is still fine.
- `heightScale`: 55 is rolling veld with koppies; 20 is flat Karoo; 120 is mountains.
- `roads`: polylines with a width. The terrain is levelled across the road and coloured.
- `railway.points`: the loop. `blockhouseSpacing` controls how many blockhouses (and sentries) you get.
- `vegetation`: counts of trees, rocks and grass tufts.

## Add a town or farm

Append to `data/towns.json`:

```json
{
  "id": "nuwedorp",
  "name": "Nuwedorp",
  "position": [400, -300],
  "rotation": 15,
  "clearRadius": 80,
  "buildings": [
    { "type": "house", "sign": "", "offset": [0, 0], "rotation": 0, "size": [8, 4, 7] },
    { "type": "shop",  "sign": "WINKEL", "offset": [14, 0], "rotation": 0, "size": [10, 4, 8] },
    { "type": "well",  "offset": [-10, 10] }
  ]
}
```

The ground is flattened within `clearRadius`. Buildings face +z in the town's own frame; `rotation`
on a building turns it, `rotation` on the town turns everything. Types: house, shop, hotel,
courthouse, smithy, farmhouse (all the same recipe with different colours and a sign), church,
station, barracks, tent, kraal, well, hitchrail, blockhouse.

Then put a road to it in `world.json` and people in it in `npcs.json`.

## Add a building type

`scripts/World/TownBuilder.cs`: add a case to `BuildOne` and a method that adds boxes, cylinders,
prisms and signs from `Props`. Use `Props.SolidBox` for anything the player should collide with.
Sizes are metres. Look at `Well` for the smallest example and `Station` for the largest.

## Add a person

Append to `data/npcs.json`:

```json
{ "id": "smous", "name": "Jacob the Smous", "faction": "civilian", "role": "pedlar",
  "town": "driefontein", "offset": [-30, 20], "dialogue": "smous", "wanderRadius": 6 }
```

- `faction`: civilian, british, boer, outlaw.
- `weapon`: a key from `weapons.json` makes them armed (they will shoot back if provoked).
- `hostile: true`: attacks the player on sight.
- `patrol`: a list of absolute `[x, z]` points walked in a loop (instead of wandering).
- `group`: lets missions refer to several NPCs at once (`kill_group`).

## Write a conversation

Add an entry to `data/dialogue.json` keyed by the id you used in `npcs.json`:

```json
"smous": {
  "speaker": "Jacob the Smous",
  "start": "start",
  "nodes": {
    "start": {
      "text": "Needles, thread, tobacco and news. Which do you want?",
      "choices": [
        { "text": "News.", "next": "news" },
        { "text": "Tobacco (6d).", "condition": "money:6", "action": "take_money:6", "next": "start" },
        { "text": "Nothing.", "action": "end" }
      ]
    },
    "news": {
      "text": "De Wet crossed the line again last night. Or so they say.",
      "choices": [ { "text": "Thanks.", "action": "end" } ]
    }
  }
}
```

Conditions (a choice is hidden unless they all hold; combine with commas):
`mission_available:id`, `mission_active:id`, `mission_step:id:n`, `mission_done:id`, `wanted`,
`not_wanted`, `money:pence`.

Actions (run when the choice is picked; combine with commas):
`start_mission:id`, `talk_done` (tells the mission system you spoke to this NPC),
`give_money:pence`, `take_money:pence`, `give_ammo:weapon:count`, `heal`, `sleep:hours`,
`clear_wanted:pence`, `end`.

To add a new condition or action, add a case in `DialogueSystem.Holds` or `DialogueSystem.Apply`.

## Add a mission

Append to `data/missions.json`:

```json
{
  "id": "horse_thief",
  "title": "The Horse Thief",
  "description": "Someone took the smith's grey.",
  "giver": "smith",
  "rewardPence": 600,
  "requires": ["bosman"],
  "steps": [
    { "type": "goto",       "objective": "Follow the tracks north",      "position": [20, -320], "radius": 30 },
    { "type": "kill_group", "objective": "Deal with the thief",           "group": "thief" },
    { "type": "return",     "objective": "Tell Grobler the smith",        "target": "smith" }
  ],
  "spawns": [
    { "id": "thief", "name": "Piet Vos", "faction": "outlaw", "hostile": true, "weapon": "webley", "group": "thief", "position": [30, -330] }
  ]
}
```

Step types: `goto` (position + radius), `kill_group` (group), `talk` and `return` (target NPC id;
their dialogue needs a choice with `action: "talk_done"` and a condition like
`mission_step:horse_thief:2` so it only appears at the right moment). The last step pays the reward.
`requires` lists missions that must be finished first. The HUD compass shows a marker for the current
step.

To add a step type (escort, deliver an item, survive until dawn), add a case to
`MissionManager.Update` and `MissionManager.MarkerPosition`.

## Change a weapon or add one

`data/weapons.json`. `kind` is `rifle` (one shot per click) or `revolver` (hold to fire).
Give the player a new one by listing its id in `world.json` → `playerWeapons`. The model shown in
the hand is chosen by `kind` in `HumanoidModel.ShowWeapon`.

## Change the keys

`scripts/Core/InputSetup.cs`, or Project Settings → Input Map in the editor (editor mappings win).

## Replace the placeholder models

- People: `scripts/Characters/HumanoidModel.cs`. Keep the public methods (`Configure`, `Animate`,
  `SetAiming`, `SetDead`, `ShowWeapon`, `MuzzleWorld`) and build the body from a `.glb` plus an
  `AnimationPlayer` instead of boxes.
- Horse: `Horse.BuildModel()` in `scripts/Characters/Horse.cs`; keep the `Saddle` node where the rider sits.
- Buildings: `scripts/World/TownBuilder.cs`.
- Trees and rocks: `scripts/World/Vegetation.cs` (swap the meshes given to `NewMultiMesh`).
- Train: `Railway.cs`, `Locomotive` and `Wagon`.

Good free sources: Kenney (kenney.nl), Quaternius (quaternius.com), KayKit (kaylousberg.itch.io).
All CC0. Put files under `res://assets/` and load with `GD.Load<PackedScene>`.

## Change a texture or the look of the ground

All textures are generated in `scripts/World/Tex.cs`. For example `SoilAlbedo()` mixes three noise
fields into a colour; nudge the numbers and restart. To use a photo instead, keep the method name and
return `GD.Load<Texture2D>("res://textures/soil.png")` (put the file in a `textures` folder; Godot
imports it automatically).

The ground itself is `shaders/terrain.gdshader`: `near_tile` and `far_tile` set how often the detail
repeats, `rock_slope_start/end` where slopes turn to rock, and the `tint` lines decide the colour
variation. The base colours per surface (veld, road, rail, town) are in `Terrain.BuildMesh`.

Grass density, tree, shrub, rock and termite-mound counts are in `data/world.json` → `vegetation`.
Tree shapes are in `Vegetation.Trees`; the two kinds are the flat-topped acacia and the rounder
sweet thorn.

## Change the sky, time of day or weather feel

`scripts/World/DayNight.cs`. `Apply()` runs every frame and sets the sun and moon angles, light
colours, fog, cloud colours and the night lamps from the hour. The cloud layer is `shaders/clouds.gdshader`
(`coverage` for how much sky is covered, `scale` for cloud size, `speed` for drift). The physical sky's
`Turbidity` controls haze, `MieCoefficient` the sun's glare.

## Add a lamp or a lit window to something

`Props.Lantern(position)` adds a lamp that switches on at night. `Props.Glass()` is a window material
that glows at night. Both register themselves with `DayNight`; nothing else to do.

## Replace the sounds

`scripts/Audio/Sfx.cs` builds its sounds mathematically. Replace the `Build(...)` calls with
`GD.Load<AudioStream>("res://audio/rifle.wav")` and keep the method names.

## Where the save file is

`%APPDATA%\Godot\app_userdata\Veld\save.json`. Delete it to start fresh. It stores money, reputation,
position, clock, dead NPCs, finished and active missions, wanted level, health and ammunition.
